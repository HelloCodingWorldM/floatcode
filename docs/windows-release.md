Windows 10/11 x64 public test build. Download the file ending in **Windows-x64-Setup.exe** below.

Run the installer. It installs for your current Windows account and creates Start menu and desktop shortcuts. No Node.js, terminal, API keys, or GitHub login are needed. Sign in using your existing FloatCode account; Mac and Windows users share the same collaboration rooms.

- Transparent or white background, optional pinning, draggable window, lower-right resize handle.
- Windows-style window controls; maximize fills the current monitor without covering the taskbar.
- Alt+1: hide/show. Alt+2: edit/pass-through. Alt+3: quit.
- Ctrl + / Ctrl - / Ctrl 0: increase, decrease, or reset code font size.
- Live collaboration and guest invitations use the existing service.

This beta is not digitally signed. Windows SmartScreen may display an unknown-publisher warning. Only use the installer from this repository; its SHA-256 checksum is attached. Automated native Windows startup and window-control checks run before publication. Multi-monitor/DPI, click-through behavior over other applications, and real Mac-to-Windows collaboration still need hands-on testing.
